# 今日运势

群聊里常见的签到运势：智能体为发言的成员生成一张卡片，带运势等级、1–99 的幸运数字、宜忌各两条，以及连续签到天数。文案都是轻松的日常建议，仅供娱乐。

## 工具

| 工具           | 说明                                                                                    |
| -------------- | --------------------------------------------------------------------------------------- |
| `draw_fortune` | 无参数，为频道里最近一位发言的成员生成当天的运势与 PNG 卡片，并记录签到，返回 `assetId` |

智能体拿到结果后，用 `send_channel_message` 的 image 块发送图片；扩展本身不在频道发言。

运势按成员与上海日期确定，同一天无论抽几次都相同，午夜换日。被抽取的是「最近一位发言的成员」：群里消息很多时，可能不是请求的那个人，结果中会带上成员名，智能体转述前应当核对。没有可识别的发言成员（例如内置频道）时返回说明。

## 权限与配置

不需要配置、凭据或网络访问，只使用：

- `storage: { scopes: ['member'] }`：每个频道里的每位成员一条签到记录（最近签到日期与连续天数）；
- `assets: { write: true }`：把渲染出的 PNG 保存为当前频道的 Asset。
