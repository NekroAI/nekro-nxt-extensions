# 今日运势

群聊里的每日签到小游戏：为发言的成员画一张运势卡片，记录连续签到天数。

## 能做什么

- 生成一张运势图片：运势等级、1–99 的幸运数字、宜和忌各两条；
- 同一个人同一天无论抽几次结果都一样，第二天（北京时间零点后）换新；
- 记录每位成员的连续签到天数，断签后从 1 重新开始。

## 怎么用

成员在群里说「抽个今日运势」「签到」之类的话，智能体就会生成卡片并发到群里。

## 配置与凭据

不需要任何配置或凭据。

## 权限

- **保存成员数据**：为每个频道里的每位成员记一条签到记录（最近签到日期和连续天数），用来计算连续签到；
- **保存文件**：把生成的运势卡片保存成图片，交给智能体发送。

不联网，也不读取聊天记录。

## 注意事项

- 卡片是为「最近一位发言的成员」生成的。群里消息很多时可能对不上请求的人，智能体转述前会核对名字；
- 没有可识别发言成员的频道（例如内置对话）无法抽取；
- 运势和宜忌都是轻松的日常建议，仅供娱乐。
