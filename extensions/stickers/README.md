# 表情包

智能体在群聊里收藏别人发的表情包，聊天时按想表达的意思挑一张发出去。收藏的表情包可以在不同群之间流通，群里特有的截图和私密内容只留在原来的群。

## 能做什么

- 群里有人发了以后用得上的表情包，智能体会收藏下来，记下它表达什么、适合什么时候发、图里写了什么字；
- 聊天时想用表情包，智能体会按意思去库里找，比如「被夸了有点得意」，先确认候选图的内容再发；
- 在甲群收藏的通用表情包，乙群也能用；图里有某个群的聊天记录、昵称、账号、真实照片这类内容的，只在出现过它的群里用；
- 智能体发现描述写错了会顺手改正，发现不该带到别的群的会改成只在本群用，不是表情包的会移进回收站；
- 在左侧导航的「表情包」页面浏览全部表情包，按意思搜索，修改描述，决定一张图能不能流通，恢复回收站里的图；
- 在页面上一次导入很多张图片或压缩包，选一个支持视觉的模型自动写好用途和图中文字。

## 怎么用

给智能体启用本扩展后，平时不需要做什么：智能体会自己收藏和使用。也可以直接说：

- 「这张收藏一下」
- 「发个表示无语的表情包」
- 「这张别发到别的群了」

想把以前攒的表情包一次放进来：打开「表情包」页面，点「导入」，选择图片或包含图片的 zip，再选一个支持视觉的模型（在「设置 → 模型」里配置），模型会为每张图写好用途和图中文字，并判断能不能在群之间流通。上传完成后导入在后台进行，可以关掉窗口；模型没判断成的图先只在本群用，之后可以在页面上补写。

## 设置

- **智能体设置**：收藏方式（看到合适的就收藏、有人要求时才收藏、不收藏）；能用的表情包（所有智能体收藏的，或只用自己收藏的）；搜索时附几张候选图。
- **频道面板**：每个群可以单独设置收藏的图只在本群用、不收藏，或者只用本群出现过的、不发表情包。比较敏感的群可以在这里一次设好。
- **页面**：「暂停流通」打开后，每个群只用在本群出现过的表情包。

想让智能体按意思找得更准，可以在「设置 → 检索」下载语义模型。不下载也能用，按关键词找。

## 权限

- **把频道里的图片收进扩展资源库，之后可以在其他频道使用**：表情包要能在群之间流通；只有当前群里看得到的图才能收进来。
- **建立可搜索的索引**：按意思查找表情包。
- **使用本机已配置的模型，可以发送图片**：只在页面导入时使用，用你选的模型给图片写用途和图中文字。
- **在本机保存扩展数据**：保存表情包的描述、群设置和导入进度。
- **读取频道与智能体信息**：页面上显示表情包来自哪个群、是哪个智能体收藏的。

不访问网络，也不会自己在群里发言，图片都由智能体通过聊天发送。

## 注意事项

- 只收藏 PNG、JPEG、GIF、WebP 图片，单张最大 8 MB；导入时单张最大 20 MB，按文件内容识别，扩展名不对也能导入；
- 智能体在发图前会先确认候选图的内容。模型没有视觉能力时，它只能看到文字描述；
- 移进回收站的图 30 天后彻底删除；
- 已经发到群里的消息不能撤回，改成「只在本群」只影响之后。
