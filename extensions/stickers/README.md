# Emotion 表情包

让智能体用表情包表达情绪。群里大家常发的表情包会自动收集下来，智能体回复时挑一张合适的发出；公共表情包在各个频道共享，已有的表情包可以批量导入。

## 功能

- **自动收集**：同一张图被群里不同的人发过（默认两个人），就自动收进库里，由标注模型记下它表达的情绪、适用场合和图中文字；智能体也可以把一张图交来收藏。收集在后台进行，不占用智能体的回复；
- **按情绪检索**：想表达「被夸了有点得意」时，智能体按意思检索，核对候选图后再发；
- **适时提醒**：按使用频率，隔几次回复提醒智能体可以配一张表情包；「智能判断」跟着群里发表情包的多少调整；
- **公共与来源频道**：通用的表情包设为公共，所有频道都能用；含有聊天截图、昵称、账号、真实照片等内容的，仅限来源频道使用；
- **自我整理**：智能体发现描述不对会修正，发现不适合公共的会改为仅限来源频道，不是表情包的会移入回收站；
- **管理页面**：在左侧导航的「表情包」页面浏览、检索、编辑表情包，调整使用范围，恢复回收站中的图片；
- **批量导入**：一次导入多张图片或 zip，由视觉模型自动标注。

## 使用

为智能体启用后，在「表情包」页面点「收集设置」选择一个标注模型（支持视觉的模型，在「设置 → 模型」中配置），自动收集就会开始。没有选择时，收集到的图会先排队，选好后自动整理入库。

也可以直接对智能体说：

- 「这张收藏一下」
- 「发个表示无语的表情包」
- 「这张别发到别的群了」

导入已有的表情包：打开「表情包」页面，点「导入」，选择图片或 zip，再选择一个视觉模型（在「设置 → 模型」中配置）。上传完成后导入在后台进行，可以关闭窗口。

## 设置

**智能体设置**

| 设置项         | 选项                                                                                 |
| -------------- | ------------------------------------------------------------------------------------ |
| 收集策略       | 自动收集、被要求时收集（只收智能体交来的）、不收集                                   |
| 可用表情包     | 所有智能体收集的、仅自己收集的                                                       |
| 使用频率       | 智能判断、频繁（约每 3 次回复）、适中（约每 5 次回复）、偶尔（约每 10 次回复）、极少 |
| 检索预览图数量 | 不提供、2 张、4 张、6 张；需要模型支持视觉                                           |

**频道面板**：单独设置本频道的收集方式（自动判断是否公共、全部仅限本频道、不收集）和使用范围（公共和本频道的、仅本频道的、不使用）。

**收集设置**（「表情包」页面）：

| 设置项   | 选项                                                       |
| -------- | ---------------------------------------------------------- |
| 标注模型 | 已配置的视觉模型；不选择时收集到的图只排队                 |
| 收集门槛 | 出现一次就收集、两个人发过后收集（默认）、三个人发过后收集 |
| 同时处理 | 1–8 张，默认 2 张；导入和收集共用                          |

页面上打开「暂停跨频道使用」后，各频道只使用自己收集的表情包。

在「设置 → 检索」下载语义模型后，按意思检索会更准确；不下载时按关键词检索。

## 权限

- **把频道里的图片收进扩展资源库，之后可以在其他频道使用**：公共表情包需要跨频道使用；只能收集当前频道中可见的图片。
- **建立可搜索的索引**：按情绪和场合检索表情包。
- **使用本机已配置的模型，可以发送图片**：用于标注收集和导入的图片。
- **在本机保存扩展数据**：保存表情包信息、频道设置、收集队列和导入进度。
- **查看频道里的新消息**：记下哪些图被谁发过，用来自动收集；只记录图片编号和发送者，不保存聊天内容。
- **读取频道与智能体信息**：在页面上显示来源频道和收集者。

本扩展不访问网络，也不会主动在频道发言，图片都由智能体在聊天中发送。

## 限制

- 支持 PNG、JPEG、GIF、WebP。聊天中收集的单张不超过 8 MB，导入的单张不超过 20 MB；导入时按文件内容识别格式；
- 自动收集不收长图和照片尺寸的大图；平台标出的表情包只作参考，从电脑拖进来的表情包同样会收集；
- 每张新表情包调用一次标注模型，计入该模型的用量；
- 模型不支持视觉时，智能体只能看到文字描述；
- 回收站中的图片保留 30 天；
- 已发出的消息无法撤回，修改使用范围只影响之后的使用。
