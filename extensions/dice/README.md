# 掷骰与抽签

让智能体掷骰子、做百分骰检定或随机抽签。结果由宿主的安全随机数决定，智能体只负责播报，适合跑团、游戏和日常「帮我选一个」。

## 工具

| 工具         | 说明                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| `roll_dice`  | 按表达式掷骰：`3d6+2`、`d20`、`d%`、`2d8+1d4-1`，一次最多 100 颗、每颗最多 1000 面 |
| `check_d100` | 百分骰检定：与目标值比较，给出大成功、极难成功、困难成功、成功、失败或大失败       |
| `draw_lots`  | 从给出的选项中不重复地抽取若干个                                                   |

## 权限与配置

不需要任何权限与配置。
