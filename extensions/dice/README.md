# 掷骰与抽签

让智能体替你掷骰子、做跑团检定或随机抽签，结果由程序随机决定，智能体只负责播报。

## 能做什么

- 按常见写法掷骰：`3d6+2`、`d20`、`d%`、`2d8+1d4-1`，列出每颗骰子的点数和总和；
- 百分骰检定：给出技能值，判定大成功、极难成功、困难成功、成功、失败或大失败；
- 随机抽签：从你给出的选项里不重复地抽一个或几个。

## 怎么用

在启用了本扩展的智能体所在的对话里直接说，例如：

- 「帮我掷 3d6+2，用途是攻击」
- 「侦查 60，过个检定」
- 「火锅、烧烤、拉面里帮我抽一个」

## 配置与凭据

不需要任何配置或凭据。

## 权限

不需要任何权限：不联网、不保存数据。

## 注意事项

- 一次最多掷 100 颗骰子，每颗最多 1000 面；
- 抽签需要 2 到 100 个不同的选项，重复的选项只算一个；
- 检定规则：掷出不超过技能值即成功，不超过一半为困难成功，不超过五分之一为极难成功，掷出 1 为大成功，失败且掷出 96 及以上为大失败。
