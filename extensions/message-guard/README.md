# 消息守卫

按关键词控制智能体对消息的反应：让某些消息对它不可见、不触发回复，或者不用 @ 也能叫醒它。

## 能做什么

- **屏蔽**：含屏蔽关键词的消息对智能体隐藏，也不会触发回复；
- **静默**：含静默关键词的消息不触发回复，但智能体之后仍能看到；
- **唤醒**：含唤醒关键词的消息即使没有提到智能体，也会让它回复。

## 怎么用

在扩展配置里逐条填写关键词即可，例如：

- 屏蔽：`广告`、`加微信`
- 静默：`[自动转发]`
- 唤醒：`小助手`、`请回答`

同一条消息命中多种关键词时，按「屏蔽 > 静默 > 唤醒」处理，即使消息提到了智能体也一样。没有命中任何关键词的消息照常处理。

## 配置与凭据

| 配置       | 说明                                         |
| ---------- | -------------------------------------------- |
| 屏蔽关键词 | 命中任意一个：对智能体隐藏，不触发回复       |
| 静默关键词 | 命中任意一个：不触发回复，智能体之后仍能看到 |
| 唤醒关键词 | 命中任意一个：没提到智能体也会触发回复       |

三项默认都是空的。不需要凭据。

## 权限

- **读取频道里的全部新消息**：要判断每条消息该不该唤醒智能体，必须先看到它，因此启用时需要确认这项权限。扩展只在本地比对文字，不联网、不保存、不转发任何内容。

## 注意事项

- 只影响启用了本扩展的智能体；**消息仍然保留在频道记录里**，屏蔽不是撤回或删除；
- 匹配方式是「消息里包含这段文字」，不支持正则表达式；不区分大小写和全角半角；
- 目前无法分辨发消息的是不是其他机器人，所以其他机器人的消息同样按关键词处理；
- 修改关键词后保存配置即生效。
