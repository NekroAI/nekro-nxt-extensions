# 群管助手

让智能体在 OneBot 11 群聊中执行管理动作。禁言、移出成员和修改名片都属于高风险操作，**启用时需要人工确认平台动作权限**，机器人账号也必须具备平台要求的管理权限。

## 工具

| 工具              | 说明                                                                            |
| ----------------- | ------------------------------------------------------------------------------- |
| `mute_member`     | `memberId` 与 `minutes` 必填，禁言 1 到 43200 分钟，必须是整数                  |
| `unmute_member`   | `memberId` 必填，解除禁言；对应平台 `mute_member` 的零秒时长                    |
| `kick_member`     | `memberId` 必填，移出成员并允许其重新申请加入                                   |
| `set_member_card` | `memberId` 与 `card` 必填，原样设置名片；本扩展限制最多 80 字，空字符串表示清除 |

成员 ID 使用当前群上下文中的 `mbr_...`（例如虚构的 `mbr_ALICE`），不能使用昵称或平台账号。工具没有默认成员与默认时长。

## 权限与配置

不需要扩展配置或凭据，连接地址与凭据由已配置的 OneBot 11 连接管理。

- `platform.actions` 只声明 Adapter `onebot-11` 的 `mute_member`、`kick_member` 与 `set_member_card`。解除禁言复用禁言动作，不声明不存在的 `unmute_member`。
- `context` 声明一段最多 500 字的静态使用约束。没有网络、原始接口透传、历史、存储或模型权限。
- 每次执行先检查当前频道是群聊，再查询 `platform.actions()` 确认动作可用。私聊、内置频道、其他平台或未批准的动作会返回中文说明。

动作出现在列表中不代表协议端一定实现了对应接口，也不代表机器人具备管理员权限；平台失败会返回说明。平台回执结果不明时，结果会提示先核实群内状态，不要自动重试；调用本身出错（多发生在请求到达平台之前）时返回「操作没有执行」与简短原因。预览与导入验证不会执行真实平台动作，结果中会保留预览说明。

## 使用约束

只在群主或管理员明确要求，或已确认的群规明确规定处理方式时执行。执行前复述对象、动作与禁言时长；非禁言动作说明不涉及时长。不要对机器人自身或群主执行成员管理动作，对象或授权不明时先人工确认。

当前公开 SDK **不提供成员角色、群主身份或机器人自身的成员 ID**。上述授权和对象保护是给智能体的提示约束，不是代码层的身份校验；平台仍会执行自身权限检查。需要强制校验身份的场景，应等待 SDK 提供权威角色与自身身份查询能力。

## 作为参考

示范按 Adapter 精确声明权限、查询动作可用性、把分钟转换为平台秒数、处理不确定回执，以及 `defineTool<Args, Result>` 的扁平参数和简短输出。所有 `verificationInput` 都为 `{}`：即使动作可用，也只查询能力并返回缺少参数，不调用管理接口。
