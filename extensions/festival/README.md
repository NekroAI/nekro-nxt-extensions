# 节日提醒

每天上海时间 08:00 检查当天是否有收录的节日。节日当天向智能体提供节日名称与习俗要点，由智能体结合群聊氛围决定是否问候、如何问候；普通日不唤醒智能体。还可以随时查询近期节日。

## 工具

| 工具                 | 说明                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| `upcoming_festivals` | `days` 为 1–90 的整数，默认 30；包含上海日期的今天，共查询 days 天，起止日都包含 |

结果按日期排序。同一天有多个节日时全部列出，例如 2031-10-01 同时是国庆节和中秋节。查询为空、参数无效或查询失败时，返回可读的中文说明。

## 配置

| 配置         | 说明                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 包含国际节日 | 默认开启；本扩展将情人节、妇女节、劳动节、儿童节、圣诞节列入开关范围，关闭后不查询或提醒这些节日 |

开关不影响元旦、植树节、青年节、教师节、国庆节及农历节日。这是扩展的筛选约定，不是节日的法定分类。扩展不提供法定放假或调休安排。

## 权限

只声明 `jobs.declared`：`id: festival-morning`、`cron: 0 8 * * *`、`timezone: Asia/Shanghai`。宿主在启用该扩展的智能体所绑定的每个频道运行固定计划，负责到期去重。

无需网络、存储、Asset、凭据或运行时任务权限，不执行平台动作，不直接发送消息。`onJob` 在 factory 阶段注册；非节日与内置频道返回 `{ wake: false }`，节日返回 `note`，由智能体决定如何问候。

宿主离线期间错过的触发会合并为一次补跑：补跑发生在节日当天 08:00 之后会照常提醒，节日已经过去则不再发送过期问候。

## 节日与日期来源

公历固定节日包括元旦（01-01）、情人节（02-14）、妇女节（03-08）、植树节（03-12）、劳动节（05-01）、青年节（05-04）、儿童节（06-01）、教师节（09-10）、国庆节（10-01）、圣诞节（12-25）。

## 作为参考

示范 Manifest 固定任务、factory 阶段的 `harness.onJob`、普通日抑制唤醒、按上海日期查询和配置默认值。查询与提醒共用日期表，Host 单文件只导入 SDK。`defineTool<Args, Result>` 约束工具参数和结果，`output.render` 输出简洁文字。

测试用抽样日期独立核对日期表，并覆盖闰月不重复、跨年、上海零点与离线补跑。`verificationInput` 只查询未来 30 天，无写入或外部副作用。
