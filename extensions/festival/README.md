# 节日提醒

节日当天早上提醒智能体在群里送上问候，也可以随时查询近期有哪些节日。

## 能做什么

- 每天北京时间 8:00 检查当天是不是节日；是的话把节日名称和习俗要点告诉智能体，由它结合群里的氛围决定要不要问候、怎么问候；
- 普通日子什么也不做，不会打扰智能体；
- 查询包括今天在内未来 1–90 天的节日（默认 30 天）。

收录的节日：

- 公历：元旦、情人节、妇女节、植树节、劳动节、青年节、儿童节、教师节、国庆节、圣诞节；
- 农历：春节、元宵节、端午节、七夕、中秋节、重阳节、除夕。

## 怎么用

启用后节日提醒自动进行。想查询时可以问：

- 「最近一个月有什么节日？」
- 「下周有没有节日？」

## 配置与凭据

| 配置         | 说明                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 包含国际节日 | 默认开启。关闭后不再查询或提醒情人节、妇女节、劳动节、儿童节和圣诞节 |

不需要凭据。

## 权限

- **定时任务**：每天北京时间 8:00 运行一次检查，在启用了本扩展的智能体所在的每个频道各运行一次。

不联网、不保存数据，也不会自己在群里发言。

## 注意事项

- 农历节日日期内置了公历 2026–2035 年，来自香港天文台公历与农历对照表；超出这个范围时只提醒公历节日；
- 不提供法定放假和调休安排；
- NekroNXT 离线错过了提醒时，恢复后如果还是节日当天会补上提醒，节日已经过去则不再补发；
- 内置对话频道不会收到节日提醒。
