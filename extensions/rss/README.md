# RSS 订阅

在对话里订阅博客、新闻等 RSS 或 Atom 源，有新文章时由智能体告诉大家。

## 能做什么

- 为当前频道订阅 RSS 或 Atom 源，每个频道最多 20 个；
- 定时检查更新：有新文章时把标题和链接交给智能体转述，没有更新时不打扰；
- 查看订阅列表、取消订阅、立即检查一次；
- 某个源连续 3 次取不到内容时提醒你检查地址。

## 怎么用

例如对智能体说：

- 「订阅 https://news.example.com/feed.xml，叫它示例新闻」
- 「列出这个群的 RSS 订阅」
- 「立即检查一下示例新闻」
- 「取消第 2 个订阅」

刚订阅时只记住已有的文章，不会把旧文章当新内容推送。

在频道的侧栏可以看到「RSS 订阅」面板，列出当前智能体在这个频道的订阅、最近检查时间和是否取回失败；订阅和取消仍通过对话完成。

## 配置与凭据

在每个智能体的「智能体配置」里设置：

| 配置             | 说明                                                                        |
| ---------------- | --------------------------------------------------------------------------- |
| 检查间隔（分钟） | 15、30（默认）、60 或 180。只对之后新建的订阅生效，已有订阅需取消后重新订阅 |

不需要凭据，也不支持需要账号密码的订阅地址。

## 权限

- **访问任意公网网址**：订阅地址由你在对话中给出，无法事先列出，因此启用时需要确认这项权限。NekroNXT 仍会拦截局域网和本机地址；
- **保存数据**：按智能体和频道分别保存订阅列表和已读记录，不同频道互不影响；频道面板读取同一份数据来展示订阅；
- **定时任务**：每个订阅一个定时检查，所有频道合计最多 50 个。

不读取聊天记录，也不会自己在群里发言。

## 注意事项

- 检查按整点刻度进行（例如每 30 分钟在 :00 和 :30），不是从订阅那一刻开始计时；
- 每个源一次最多转述 5 条新文章，其余的同样标记为已读，不会留到下次；
- 每个源只记得最近 200 篇文章，很早以前的文章重新出现时可能被当作新文章；
- 定时检查被手动删除后，查看列表或立即检查时会自动恢复。
