# 团队采购清单

群里谁说要买什么，智能体就记进同一份采购清单；负责采购的人打开「采购清单」页面，一眼看到要买什么、谁提的，买好后勾选。

## 能做什么

- 在群里对智能体说要买的东西，它会记下物品、数量、备注和提出的人；同样的东西还没买时不会重复记；
- 问智能体「还有什么没买」，它会列出清单；也可以让它把某一项标记为已买；
- 在左侧导航的「采购清单」页面查看全部记录，勾选已买、删除某一项，或一键清理已买的；
- 给多个智能体启用时，它们记在同一份清单里。

## 怎么用

例如在群里对智能体说：

- 「帮我记一下，要买两箱 A4 打印纸」
- 「采购清单里还有什么没买？」
- 「第 2 项已经买了」

## 配置与凭据

不需要任何配置或凭据。

## 权限

- **保存数据**（安装时确认）：清单保存在本机，页面读取和修改它；
- **保存数据并在智能体之间共享**（给智能体启用时确认）：智能体记下的东西写进同一份清单，所以多个智能体能看到彼此记的内容。

不联网，也不会自己在群里发言。

## 注意事项

- 清单最多 200 项，满了以后请在页面上清理已买的；
- 「提出的人」取自对智能体说话的那条消息的发送者；
- 删除和清理不能撤销。
