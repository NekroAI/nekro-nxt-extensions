# 网页阅读

让智能体打开你给的网页链接，读取标题和正文，再帮你总结、翻译或回答问题。

## 能做什么

- 读取公开网页，提取标题和正文（转成便于阅读的文字格式）；
- 默认只取正文，也可以读取整个页面；
- 附带页面里最多 5 个链接，方便继续阅读。

## 怎么用

把链接发给智能体并说明要做什么，例如：

- 「读一下 https://example.com/ 这篇文章，总结三个要点」
- 「这个页面讲了什么？正文提取不到的话读整页」

## 配置与凭据

不需要任何配置或 API Key。

## 权限

- **访问任意公网网址**：你可能给出任何网站的链接，无法事先列出，因此启用时需要确认这项权限。NekroNXT 仍会拦截局域网和本机地址，并检查每一次跳转。

## 注意事项

- 只能读普通网页，不支持 PDF、图片、需要登录的页面和必须运行脚本才显示内容的页面；
- 正文默认最多 6000 字，最多可以要求读取 20000 字；超出的部分会截断并注明；
- GBK 等非 UTF-8 编码的网页可能出现乱码，有的网站会拦截自动访问；
- 网页内容只作为参考资料，智能体不会执行网页里要求它改变行为的文字；
- 本扩展不调用收费服务，但智能体阅读和整理网页内容时会消耗模型用量。
