# 语音合成

让智能体将文字合成为 MP3 音频。工具保存文件并返回 `assetId`，由智能体使用 `send_channel_message` 的 `audio` 块以音频发送。

## 配置

| 配置     | 说明                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| 服务地址 | API 基础地址，默认 `https://api.openai.com/v1`；例如 `https://speech.example.com/v1`，自动追加 `/audio/speech` |
| API Key  | 在所选服务商控制台创建，作为只写凭据保存；没有默认值                                                           |
| 模型     | 默认 `tts-1`，可改为服务商兼容的语音模型                                                                       |
| 音色     | 默认 `alloy`，填写所选服务和模型支持的名称                                                                     |

## 工具

| 工具    | 说明                                                                                                                           |
| ------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `speak` | `text` 是非空朗读文本，去除首尾空白后最多 1000 字（Unicode 码点）；`voice` 可覆盖默认音色；返回 `assetId` 和宿主识别的媒体类型 |

例如 `speak({ text: '欢迎来到示例故事会。', voice: 'alloy' })`。超过上限会给出说明，不会静默截断或自动分段发起多个付费请求。

## 服务要求与费用

服务必须兼容 `POST /audio/speech`、Bearer Key 和 `{ model, input, voice, response_format: 'mp3' }`，直接返回 MP3 二进制，不能返回 JSON、文件 URL 或流式事件。接受 `audio/mpeg`、`audio/mp3` 或 `application/octet-stream` 的响应类型，保存时以 `audio/mpeg` 提交，音频的格式、类型与大小由宿主保存文件时校验，结果中的媒体类型以宿主识别为准。请求字段见 [OpenAI 语音接口](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create)。

每次合成按服务商计费，由用户自己的 Key 所属账号承担。请确认模型和音色权限、余额及价格；请求超时或保存文件失败时，服务端可能仍在生成或已完成合成并计费，重试前先确认。本扩展不自动重试，也不承诺免费。朗读文本和 Key 会发送给配置的服务，请选择可信地址并优先使用 HTTPS。

## 权限

- `network.mode: 'config'`，仅按 `endpoint` 配置字段放行服务主机；
- `assets: { write: true }`，在当前频道保存合成音频。

无需频道发送权限、存储或上下文能力。凭据通过 `ctx.nxt.secrets.get('apiKey')` 读取，没有凭据时不会联网。

## 作为参考

示范宿主二进制响应的 `base64` 字段、文本长度检查、配置音色与调用参数的优先顺序，以及通过 Asset 交付音频。异常时返回以「语音合成失败：」开头、附截断到 200 字原因的说明，超时会额外提示服务端可能仍在生成并已计费。验证样例使用空 `text`，即使存在凭据也在联网前返回输入说明，不合成语音、不计费。
