# 语音合成

让智能体把一段文字读出来，以语音消息发到对话里，使用你自己的 OpenAI 或兼容服务的 API Key。

## 能做什么

- 把最多 1000 字的文字合成为 MP3 语音；
- 可以设置默认音色，也可以在对话里临时指定。

## 怎么用

例如对智能体说：

- 「用语音读一下：欢迎来到今晚的故事会」
- 「换个音色，再读一遍刚才那段」

## 配置与凭据

服务地址、API Key 和模型在扩展的「本机配置」里填写一次，所有智能体共用；音色在每个智能体的「智能体配置」里分别设置。

| 配置     | 位置       | 说明                                                                                      |
| -------- | ---------- | ----------------------------------------------------------------------------------------- |
| 服务地址 | 本机配置   | 默认 `https://api.openai.com/v1`。用兼容服务时填它的接口基础地址（保留 `/v1` 这样的路径） |
| API Key  | 本机配置   | 在服务商控制台创建。保存后只能替换，不会再显示                                            |
| 模型     | 本机配置   | 默认 `tts-1`，可改为服务商支持的其他语音模型                                              |
| 音色     | 智能体配置 | 默认 `alloy`，填所选服务和模型支持的音色名称                                              |

## 权限

- **联网**（安装时确认）：只能访问你在「服务地址」里填写的服务；
- **保存文件**（给智能体启用时确认）：把合成的音频保存下来，交给智能体发送。

## 注意事项

- **每次合成都会按服务商价格计费**，由你的 API Key 所属账号承担；
- 超过 1000 字会直接提示缩短，不会自动拆成多次付费请求；
- 扩展不会自动重试。请求超时后服务商那边可能仍在合成并计费，重试前先确认；
- 服务需要直接返回 MP3 音频数据，返回网址或流式数据的服务不受支持；
- 朗读的文字和 API Key 会发送给你配置的服务，请选择可信的服务并使用 HTTPS。
