# 图片生成

让智能体画图、改图，画好直接发到对话里。现在的画图模型能把中英文标题准确画进画面，海报、信息图、截图、漫画都能交给它。

需要 NekroNXT 0.10.0 或更新版本。默认用 NekroAPI，填上 API Key 就能用；也可以换成其他画图服务。

## 能让智能体做什么

对智能体说这些就行：

- 「做一张周六读书会的竖版海报，标题写『春日读书会』，下面写时间地点，配一点插画」
- 「把这段话做成一张推文截图，头像用一只橘猫，昵称『今天也想摸鱼』」
- 「画一张信息图，讲清楚垃圾分类的四种颜色分别装什么」
- 「画一个四格漫画：猫想偷吃鱼，被狗发现，最后两个一起吃」
- 「做一张新品奶茶的产品图，白底，杯身印上『桃桃乌龙』」
- 「把这张照片的背景换成雪山，人不要变」（同时发一张图，或回复一张图）
- 「照这张图的画风，画一只在写作业的小狐狸」

画面里的短标题、标语一般都能画对；大段小字画完最好看一眼。画得不满意时直接说哪里要改，智能体会拿这张图接着改。

## 选哪个模型

在扩展的「本机配置」里选。几个模型都能做上面这些事，区别主要在风格和细节：

| 模型                    | 特点                                       | 出图时间       |
| ----------------------- | ------------------------------------------ | -------------- |
| Nano Banana 2.1（默认） | 画面文字、信息图和多个人物的一致性更稳     | 十几到二十多秒 |
| Nano Banana 2           | 快而稳，各类题材都行                       | 十几秒         |
| Nano Banana Pro         | 写实质感和比例稳                           | 约 20 秒       |
| GPT Image 2.6 快速档    | 排版和复杂要求照做得好，适合反复出稿       | 约 20 秒       |
| GPT Image 2.6 精细档    | 细节最丰富，反复改图时人物和画面最一致     | 约 20 秒       |
| Seedream 5.0 Lite       | 写实照片和人物保持好，出 2K 大图           | 十几秒         |
| Grok Imagine 2.0        | 照片感强，人物长相保持好；中文偶尔变成繁体 | 约 10 秒       |
| GPT Image 2             | 上一代，很慢                               | 约一分半       |

GPT Image 几款只出方图、2:3 竖图和 3:2 横图，其他画幅按最接近的出。价格以 NekroAPI 网站为准。

## 配置与凭据

本机配置填一次，所有智能体共用；画幅和质量在每个智能体的「智能体配置」里分别设置。

| 配置       | 位置       | 说明                                                                                                            |
| ---------- | ---------- | --------------------------------------------------------------------------------------------------------------- |
| API Key    | 本机配置   | 用 NekroAPI 时到 [api.nekro.ai](https://api.nekro.ai) 获取；用其他服务时在它的控制台创建。保存后只能替换        |
| 模型       | 本机配置   | 默认 Nano Banana 2.1，见上表；用其他服务时选「其他模型」                                                        |
| 服务地址   | 高级       | 默认 `https://api.nekro.ai/v1`（NekroAPI）。用其他服务时填它的接口基础地址，保留 `/v1` 这样的路径               |
| 其他模型名 | 高级       | 「模型」选「其他模型」时填写                                                                                    |
| 调用方式   | 高级       | 默认「自动」，一般不用改，见「使用其他服务」                                                                    |
| 默认画幅   | 智能体配置 | 默认 1:1，智能体没有指定画幅时使用                                                                              |
| 图片质量   | 智能体配置 | 默认「低」。画面里字小、字多时选「高」更清楚，但更慢，有的服务价格也更高。对 GPT Image 和内置的 Gemini 模型生效 |

API Key 可以直接填写，也可以从凭据库里选择，包括「只用于网络请求」的凭据：扩展拿不到 Key 的原文，NekroNXT 只在请求发往服务时填入。

### 使用其他服务

展开「高级」，把「服务地址」改成该服务的接口基础地址，「模型」选「其他模型」，再填上它的画图模型名。扩展按模型名选择调用方式：

- 名字含 `gemini`、`banana` 的，按 Gemini 接口（generateContent）调用；
- 其他模型按 OpenAI 生图接口（`/images/generations`，改图走 `/images/edits`）调用。

如果你的服务只能通过对话接口（`/chat/completions`）出图，或者自动判断不对，把「调用方式」改成对应的一项。

## 权限

- **任意网络访问**（安装时确认）：访问你配置的画图服务。有的服务把生成的图片放在别的域名下（例如图床或云存储），扩展要从那里下载，所以不能只限定在「服务地址」；
- **读取文件**（给智能体启用时确认）：改图时读取你指定的参考图；
- **保存文件**（给智能体启用时确认）：把生成的图片保存下来，交给智能体发送。

## 注意事项

- **每次生成都会按服务商价格计费**，由你的 API Key 所属账号承担；请先确认余额、价格和模型调用权限；
- 一次请求 3 分钟收不到响应就算超时。超时后服务商那边可能仍在生成并计费，重试前先确认；
- 部署在本机或局域网里的画图服务也能用：填在「服务地址」里的地址允许访问，其他本机或局域网地址仍会被拦截；
- 图片描述、参考图和 API Key 会发送给你配置的服务，请选择可信的服务并使用 HTTPS；
- 从旧版本升级时，原来的服务地址、模型和画幅设置都会保留，原来的模型名留在「其他模型名」里。想换成列表里的模型，在「模型」里选一个；想用默认的 Nano Banana 2.1，清空「其他模型名」即可。
