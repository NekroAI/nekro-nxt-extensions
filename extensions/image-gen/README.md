# 图片生成

让智能体按文字描述画图，或参照对话里的图片改图，再把图发到对话里。支持 OpenAI 兼容和 Gemini 接口的画图服务，使用你自己的 API Key。

需要 NekroNXT 0.10.0 或更新版本。

默认预设是 NekroAPI：它的画图模型都实测过，填上 Key 就能用。也可以改用 OpenAI 官方或其他兼容服务，用法完全一样。

## 能做什么

- 按描述生成一张图片；
- 参照 1～4 张对话里的图片改图，或者参照人物、风格画新图；
- 支持 1:1、2:3、3:2、3:4、4:3、9:16、16:9 七种画幅；
- 每个智能体可以分别设置默认画幅和图片质量。

## 怎么用

例如对智能体说：

- 「画一只戴围巾的小狐狸，水彩风格」
- 「生成一张 16:9 的海边日落插画」
- 「把这张图的背景换成雪山」（同时发一张图，或回复一张图）

## 配置与凭据

服务地址、API Key、模型和调用方式在扩展的「本机配置」里填写一次，所有智能体共用；画幅和质量在每个智能体的「智能体配置」里分别设置。

| 配置     | 位置       | 说明                                                                                                       |
| -------- | ---------- | ---------------------------------------------------------------------------------------------------------- |
| 服务地址 | 本机配置   | 默认 `https://api.nekro.ai/v1`（NekroAPI）。用其他服务时填它的接口基础地址，保留 `/v1` 这样的路径          |
| API Key  | 本机配置   | 在服务的控制台创建；用 NekroAPI 时到 [api.nekro.ai](https://api.nekro.ai) 获取。保存后只能替换，不会再显示 |
| 模型     | 本机配置   | 默认 `gemini-3.1-flash-image`，见下方模型表；用其他服务时填它支持的画图模型                                |
| 调用方式 | 本机配置   | 默认「自动」，一般不用改，见「使用其他服务」                                                               |
| 默认画幅 | 智能体配置 | 默认 1:1；智能体没有指定画幅时使用                                                                         |
| 图片质量 | 智能体配置 | low（默认）、medium 或 high；越高越慢。只对 GPT Image 和部分 Gemini 模型生效                               |

### NekroAPI 的画图模型

| 模型                                                                       | 出图时间  | 改图 | 说明                                       |
| -------------------------------------------------------------------------- | --------- | ---- | ------------------------------------------ |
| gemini-3.1-flash-image（默认）、gemini-3-pro-image、gemini-nano-banana-2.1 | 10～20 秒 | 支持 | 画幅最灵活                                 |
| gpt-image-2.6-flare、gpt-image-2.6-sunburst                                | 20 秒左右 | 支持 | 只有 1:1、2:3、3:2，其他画幅按最接近的生成 |
| gpt-image-2                                                                | 约一分半  | 支持 | 很慢，建议保持低质量                       |
| doubao-seedream-5-0-260128                                                 | 十几秒    | 支持 | 输出 2K 大图                               |
| grok-imagine-image-2.0                                                     | 10 秒左右 | 支持 | 画幅写进描述，由模型自行把握               |

价格以 NekroAPI 网站为准。

### 使用其他服务

把「服务地址」改成该服务的接口基础地址，填上它的 Key 和画图模型名即可。扩展会按模型名选择调用方式：

- 名字含 `gemini`、`banana` 的，按 Gemini 接口（generateContent）调用；
- 其他模型按 OpenAI 生图接口（`/images/generations`，改图走 `/images/edits`）调用。

如果你的服务只能通过对话接口（`/chat/completions`）出图，或者自动判断不对，把「调用方式」改成对应的一项。

## 权限

- **任意网络访问**（安装时确认）：访问你配置的画图服务。有的服务把生成的图片放在别的域名下（例如图床或云存储），扩展要从那里下载，所以不能只限定在「服务地址」；
- **读取文件**（给智能体启用时确认）：改图时读取你指定的参考图；
- **保存文件**（给智能体启用时确认）：把生成的图片保存下来，交给智能体发送。

## 注意事项

- **每次生成都会按服务商价格计费**，由你的 API Key 所属账号承担；请先确认余额、价格和模型调用权限；
- 一次请求 3 分钟收不到响应就算超时。超时后服务商那边可能仍在生成并计费，重试前先确认；
- 扩展不会自动重试；
- 扩展会优先让服务直接返回图片数据，服务只给网址时再去下载；
- 部署在本机或局域网里的画图服务也能用：填在「服务地址」里的地址允许访问，其他本机或局域网地址仍会被拦截；
- 图片描述、参考图和 API Key 会发送给你配置的服务，请选择可信的服务并使用 HTTPS；
- 从旧版本升级时，原来的服务地址、模型和尺寸设置会保留，不会自动切换到 NekroAPI；想用 NekroAPI 时在本机配置里修改。
