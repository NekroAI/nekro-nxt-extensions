# 图片生成

让智能体按文字描述画一张图并发到对话里，使用你自己的 OpenAI 或兼容服务的 API Key。

## 能做什么

- 按描述生成一张 PNG 图片；
- 支持 1024×1024（方图）、1024×1536（竖图）、1536×1024（横图）三种尺寸；
- 可以设置默认尺寸和图片质量。

## 怎么用

例如对智能体说：

- 「画一只戴围巾的小狐狸，水彩风格」
- 「生成一张横版的海边日落插画」

## 配置与凭据

| 配置     | 说明                                                                                      |
| -------- | ----------------------------------------------------------------------------------------- |
| 服务地址 | 默认 `https://api.openai.com/v1`。用兼容服务时填它的接口基础地址（保留 `/v1` 这样的路径） |
| API Key  | 在服务商控制台创建。保存后只能替换，不会再显示                                            |
| 模型     | 默认 `gpt-image-1`；兼容服务请填它支持且能直接返回图片数据的模型                          |
| 默认尺寸 | 1024x1024（默认）、1024x1536 或 1536x1024                                                 |
| 图片质量 | low、medium（默认）或 high；越高越慢、越贵                                                |

## 权限

- **联网**：只能访问你在「服务地址」里填写的服务；
- **保存文件**：把生成的图片保存下来，交给智能体发送。

## 注意事项

- **每次生成都会按服务商价格计费**，由你的 API Key 所属账号承担；请先确认余额、价格和模型调用权限；
- 单次请求 30 秒没有响应会超时，高质量或大尺寸更容易超时，可以改用较低质量。超时后服务商那边可能仍在生成并计费，重试前先确认；
- 扩展不会自动重试；
- 只返回图片网址、不直接返回图片数据的服务不受支持；
- 图片描述和 API Key 会发送给你配置的服务，请选择可信的服务并使用 HTTPS。
