# 图片生成

让智能体按文字描述生成一张 PNG 图片。工具保存文件并返回 `assetId`，由智能体使用 `send_channel_message` 的 `image` 块发送。

## 配置

| 配置     | 说明                                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 服务地址 | API 基础地址，默认 `https://api.openai.com/v1`；例如兼容服务可填 `https://images.example.com/v1`，自动追加 `/images/generations` |
| API Key  | 在所选服务商控制台创建，作为只写凭据保存；没有默认值                                                                             |
| 模型     | 默认 `gpt-image-1`；需为 gpt-image 系列，或兼容 `output_format` 参数与下列三种尺寸的接口                                         |
| 默认尺寸 | 默认 `1024x1024`，另可选择 `1024x1536` 或 `1536x1024`                                                                            |
| 图片质量 | `low`、`medium` 或 `high`，默认 `medium`，随请求发送 `quality`                                                                   |

## 工具

| 工具             | 说明                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------- |
| `generate_image` | `prompt` 是非空描述；可用 `size` 覆盖默认尺寸；返回 `assetId`、宿主识别的媒体类型和请求尺寸 |

例如 `generate_image({ prompt: '一只戴围巾的虚构小狐狸，水彩风格', size: '1024x1024' })`。不自动重试生成请求。

## 服务要求与费用

服务必须兼容 `POST /images/generations`、Bearer Key、三种约定尺寸、`quality`、`n: 1` 与 `output_format: 'png'`，并返回 `data[0].b64_json` 中的 PNG 数据。默认模型按 [OpenAI 图片接口](https://developers.openai.com/api/reference/resources/images/methods/generate) 使用 base64 响应，不发送其不支持的旧式 `response_format` 参数。

仅返回 URL 的服务不受支持：本扩展不跨域下载图片，请选择能直接返回 base64 PNG 的服务或模型。图片数据的格式、类型与大小由宿主保存文件时校验，结果中的媒体类型以宿主识别为准。服务商还可能要求模型访问权限或账号验证，以其控制台说明为准。

宿主对单次请求有 30 秒无响应超时，高质量或大尺寸可能超时；遇到超时请改用较低质量。

每次生成按服务商计费，由用户自己的 Key 所属账号承担。请自行确认模型价格、余额和调用权限；请求超时或保存文件失败时，服务端可能仍在生成或已完成生成并计费，重试前先确认。不设置免费或固定价格的承诺。描述和 Key 会发送给配置的服务，请选择可信地址并优先使用 HTTPS。

## 权限

- `network.mode: 'config'`，仅按 `endpoint` 配置字段放行服务主机；
- `assets: { write: true }`，在当前频道保存生成图片。

无需频道发送权限、存储或上下文能力。凭据通过 `ctx.nxt.secrets.get('apiKey')` 读取，不从普通配置读取。

## 作为参考

示范凭据读取、保留 API 基础路径、显式结果类型与文件交付。缺少凭据、无效参数、服务错误或文件保存失败均返回 `{ ok: false, message }`；异常时以「生成图片失败：」开头并附截断到 200 字的原因，超时会额外提示服务端可能仍在生成并已计费。验证样例使用空 `prompt`，即使存在凭据也会在联网前返回输入说明，不生成图片、不计费。
