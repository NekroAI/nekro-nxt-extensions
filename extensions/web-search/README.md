# 网页搜索

让智能体搜索网络上的最新信息，并在回答时附上来源链接。

## 配置

| 配置         | 说明                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------- |
| 搜索服务地址 | 博查填 `https://api.bochaai.com`（默认），Tavily 填 `https://api.tavily.com`，其他地址按自建的 SearXNG 处理 |
| API Key      | 博查与 Tavily 需要，在对应服务的控制台创建；SearXNG 不需要                                                  |
| 默认返回条数 | 1 到 10，默认 5                                                                                             |

使用 SearXNG 时，需要在实例的 `settings.yml` 中把 `json` 加入 `search.formats`。

## 工具

| 工具         | 说明                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| `web_search` | 搜索关键词，可限定最近一天、一周、一个月或一年，返回标题、链接、摘要与发布时间 |

## 权限

- 访问你在配置中填写的地址（只放行「搜索服务地址」）；
- 在系统提示中加入一段固定的使用说明：需要最新信息时先搜索，并注明来源。

## 作为参考

示范凭据配置（`meta.role: 'secret'` 与 `ctx.nxt.secrets.get`）、`network.mode: 'config'` 按配置地址联网、静态提示，以及缺少凭据或服务报错时如何返回可读说明。
