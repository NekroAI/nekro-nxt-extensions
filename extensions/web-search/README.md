# 网页搜索

让智能体上网搜索最新信息，回答时附上来源链接。

## 能做什么

- 用关键词搜索网络，返回标题、链接、摘要和发布时间；
- 可以只看最近一天、一周、一个月或一年内的结果；
- 自动提醒智能体：需要最新信息或核对事实时先搜索，并注明来源。

支持三种搜索服务：博查、Tavily 和自己搭建的 SearXNG。

## 怎么用

启用后直接提问即可，例如：

- 「搜一下这周有什么新的开源大模型发布」
- 「帮我查查 Node.js 22 什么时候停止维护，给出处」

## 配置与凭据

搜索服务地址和 API Key 在扩展的「本机配置」里填写一次，所有智能体共用；默认返回条数在每个智能体的「智能体配置」里分别设置。

| 配置         | 位置       | 说明                                                                                                       |
| ------------ | ---------- | ---------------------------------------------------------------------------------------------------------- |
| 搜索服务地址 | 本机配置   | 博查填 `https://api.bochaai.com`（默认），Tavily 填 `https://api.tavily.com`，其他地址都当作自建的 SearXNG |
| API Key      | 本机配置   | 博查和 Tavily 需要，在对应服务的控制台创建；SearXNG 不需要                                                 |
| 默认返回条数 | 智能体配置 | 1 到 10，默认 5                                                                                            |

使用 SearXNG 时，要在它的 `settings.yml` 里把 `json` 加入 `search.formats`，否则会被拒绝。

## 权限

- **联网**（安装时确认）：只能访问你在「搜索服务地址」里填写的服务；
- **系统提示**（给智能体启用时确认）：加入一段固定的使用说明，让智能体在需要时先搜索并注明来源。

## 注意事项

- 博查和 Tavily 按各自的规则计费或限额，费用由你的 API Key 所属账号承担；
- 你的搜索关键词会发送给所选的搜索服务；
- 每条摘要会截短，需要全文时可以配合「网页阅读」扩展。
